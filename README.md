# Бот рассылки рекламы по ключам

Реализация по ТЗ: один бот вместо десятков отдельных ботов рекламодателей
(обход лимита Telegram в 20 ботов на чат). Каждый пользователь настраивает
свою рассылку через персональный ключ; физическую отправку в целевой чат
всегда делает этот один бот.

## Запуск на VPS

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

1. Открой `config.py`, впиши:
   - `BOT_TOKEN` — токен от @BotFather
   - `OWNER_ID` — свой Telegram ID (узнать у @userinfobot)
2. Запусти:
   ```bash
   python3 bots.py
   ```
3. Добавь бота в целевой(е) чат(ы) администратором.
4. В ЛС бота выполни `/adm` → «🎯 Целевой чат» → пришли ID чата (для супергрупп/каналов
   ID отрицательный, например `-1001234567890`; узнать можно, например,
   переслав сообщение из чата боту @getidsbot).

## Основные команды

- `/adm` — админ-панель (ключи, целевой чат, пользователи/бан, супер-админы,
  разовая обычная рассылка от владельца).
- `/admin1` — скрытая команда, редактирование оформления кнопок, которые видит
  пользователь (название, цвет, кастомный emoji, позиция).

Обе команды **не показываются** пользователям и никак не отвечают, если их
вызывает не-админ — по требованию ТЗ бот в этом случае полностью молчит.

## Выдача ключа пользователю

1. `/adm` → «🔑 Ключи» → «➕ Сгенерировать ключ» — бот покажет код вида `ADV-XXXXXXXXXX`.
2. Передай этот код пользователю лично (вне бота).
3. Рекламодатель пишет боту `/start`, затем присылает этот код обычным
   сообщением — бот его проверяет и, если код верный и свободен, активирует
   ключ и открывает меню настройки рассылки.

## Как работает форвард

Рекламодатель пересылает в ЛС бота готовый пост. Бот запоминает
`chat_id` (свою ЛС с этим пользователем) и `message_id` этого сообщения и по
расписанию делает `forward_message` из этой ЛС в целевой чат. Поэтому исходное
сообщение в ЛС с ботом удалять нельзя — иначе форвард сломается (проверить это
стоит на этапе тестирования; при необходимости легко заменить на `copy_message`
с сохранением содержимого в БД).

## Изменения в этой версии

- **Мгновенная отправка при включении.** Раньше при нажатии «Включить»
  рассылка ждала полный интервал до первой отправки. Теперь она уходит
  сразу же, а отсчёт следующего интервала начинается от этого момента
  (`handlers_user.cb_toggle` + `scheduler.send_broadcast`).
- **Время показывается в часовом поясе Алматы** (`config.DISPLAY_TZ`,
  `timeutils.py`) вместо сырой строки вида `2026-09-06T20:08:21.502676`.
  В БД всё по-прежнему хранится в UTC — меняется только отображение.
  Часовой пояс задаётся одной строкой в `config.py`, если понадобится
  Бишкек/Москва/другой — достаточно поменять `DISPLAY_TZ`.
- **Удобный отзыв ключей.** `/adm` → «🔑 Ключи» → «📋 Список ключей» теперь
  показывает каждый ключ отдельной кнопкой; открыв ключ, видно, когда он
  создан/активирован и кем, и там же можно его отозвать (с подтверждением).
- **Более насыщенное меню рекламодателя.** У списка рассылок появились
  ещё два пункта — «🆔 Мой ключ» и «ℹ️ Помощь», — чтобы там было не только
  «Новая рассылка», даже когда рассылок пока нет.
- **Тексты редактируются через `/admin1`.** Раздел `/admin1` теперь
  двухуровневый: «🔘 Кнопки» (как раньше) и «📝 Тексты» — там все
  сообщения бота сгруппированы («Рекламодателю» / «Админ-панель» /
  «Прочее»), каждое можно открыть, изменить или сбросить к значению по
  умолчанию. Плейсхолдеры вида `{count}` нужно сохранять при
  редактировании — при ошибке в них бот покажет текст как есть, не упадёт.

## Что стоит проверить/доработать перед боевым запуском

- **`style` и `icon_custom_emoji_id`** в `InlineKeyboardButton` — эти поля
  использованы по аналогии с твоими предыдущими ботами (Bot API 9.4,
  09.02.2026). Если после `pip install -r requirements.txt` aiogram 3.30.0
  ругается на неизвестные параметры — пришли текст ошибки, поправлю под
  точную сигнатуру.
- Ограничение группы `/admin1` — команда скрыта только тем, что не в списке
  команд бота (`/setcommands` в BotFather не включает её) и защищена
  `IsAdmin()`; это не «секретность через код», а обычная проверка прав.
- Нагрузочное тестирование очереди отправки на 70+ рассылках одновременно.

## Структура проекта

```
config.py           — настройки запуска (токен, OWNER_ID, лимиты)
database.py          — вся работа с SQLite
texts.py              — тексты сообщений
keyboards.py          — inline-клавиатуры
states.py              — FSM-состояния
filters.py              — IsAdmin / NotBanned
handlers_key.py          — /start, приём ключа, логика молчания
handlers_user.py          — меню рекламодателя
handlers_admin.py          — /adm
handlers_admin1.py          — /admin1 (оформление кнопок)
scheduler.py                 — фоновая отправка рассылок по расписанию
bots.py                        — точка входа
```
