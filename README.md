# adbot: рассылка рекламы партнёров через одного бота

В группах состоит один бот с правами администратора. Партнёры не добавляют
своих ботов: каждый получает кабинет в этом боте, присылает пост, и бот
пересылает его в группу с интервалом, который задаёт администрация.

## Как это работает

- **Вход только по ссылке.** Владелец бота создаёт кабинет и получает одноразовую
  ссылку. Партнёр переходит по ней и попадает в кабинет. Посторонним бот не
  отвечает вообще.
- **Кабинет привязан к организации**, а не к человеку. Сменить владельца кабинета
  можно новой ссылкой: рассылки, расписание и счётчики остаются, прежний доступ
  отключается. В кабинете может быть один помощник.
- **Пост пересылается как есть.** Партнёр пишет пост боту или пересылает его из
  канала, группы, от человека или бота. Бот кладёт его в хранилище и оттуда
  пересылает в группу. Сохраняются премиум-эмодзи, медиа, альбомы и шапка
  Переслано от.
- **Партнёр может:** создать рассылку (по умолчанию до 3 на кабинет), посмотреть
  превью, заменить пост, поставить на паузу, удалить. Интервал он не меняет.
- **Владелец бота может:** остановить и возобновить любую рассылку, удалить её,
  заморозить кабинет, менять число мест (до 10), задавать общий интервал и свой
  интервал для группы, скрывать группы от партнёров.
- **Антифлуд.** Отправки идут по одной: не чаще одной в секунду и не чаще одной в
  3 секунды в одну группу, даже если десятки постов подошли одновременно.

## Запуск (Docker)

1. Создайте бота в @BotFather.
2. Создайте приватный канал или группу для хранилища и канал для бэкапов.
   Добавьте бота администратором в оба.
3. Скопируйте `.env.example` в `.env` и заполните.
4. Запустите:

```bash
docker compose up -d --build
docker compose logs -f
```

5. Напишите боту `/adm`. Добавьте бота администратором в рабочие группы: они
   появятся в разделе Группы. Включите группу и откройте её партнёрам.
6. Раздел Кабинеты, кнопка Создать кабинет. Перешлите ссылку партнёру.

Обновление: `git pull && docker compose up -d --build`. База лежит в `./data`.
База прежней версии (с зеркалами) несовместима: бот сам переименует её в
`adbot.db.old-...` и начнёт с чистой.

## Группы

- 🟢 включена: в группу идёт рассылка.
- 🔒 скрыта: партнёры её не видят. Владелец может рассылать и в скрытые группы:
  создайте кабинет для себя и включите в его карточке режим Группы: все.

## Бэкап и перенос

Бэкап уходит в `BACKUP_CHAT_ID` по расписанию и по кнопке Бэкап.
Восстановление или перенос на другой сервер:

```bash
docker compose down
gunzip -c adbot-XXXX.db.gz > data/adbot.db
docker compose up -d
```

## Если бота забанили

1. Создайте нового бота, добавьте его администратором в группы, хранилище и
   канал бэкапов.
2. Замените `BOT_TOKEN` в `.env` и выполните `docker compose up -d`.
3. Кабинеты, рассылки и доступы сохраняются: они привязаны к Telegram ID.
   Партнёрам достаточно открыть нового бота и нажать /start. Сообщить им адрес
   нового бота нужно самостоятельно: бот не может написать человеку первым.

## Структура

```
main.py         запуск: бот, планировщик, бэкапы
config.py       настройки из .env
db.py           схема SQLite, индексы, кэш доступа
cabinet.py      кабинет партнёра и вход по ссылке
admin.py        админка владельцев (/adm)
posts.py        приём поста в хранилище и пересылка
scheduler.py    рассылка по интервалам с антифлудом
middlewares.py  фильтр посторонних, антифлуд кнопок
backup.py       бэкап в канал
tests/          проверки: python3 -m tests.test_db, test_scheduler, test_flow
```
